# ADR-006: Idempotency Key Strategy for Financial & Stock Safety

## Context
Network retries or user double-clicking "BUY NOW" can cause duplicate HTTP POST requests to reach the server.

## Decision
All mutation routes require an `Idempotency-Key` HTTP header. The system stores idempotency records with unique database constraints.

## Rationale
Repeated requests with identical idempotency keys return the existing reservation or payment object with `is_duplicate: true`, preventing duplicate stock holds or duplicate payment charges.
